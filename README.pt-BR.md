# interval-merge-core

União, lacunas e cobertura de intervalos fechados sobre números finitos.
Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 5 testes, node:test, sem dependências
npm run demo
```

Intervalos que se tocam unem; no máximo 100000. MIT — veja `LICENSE`.
